## 远程图片与离线使用

`imageMode` 为 `remote`，图片地址直接指向原站。仓库及独立导出包不保存、镜像或分发图片，不提供批量下载，页面也不预取相邻大图。缩略图按页面显示加载，选中某一条后才加载对应中图，原始 PNG 通过单独链接在原站打开。

`index.html` 内嵌完整筛选数据，可通过 `file://` 直接打开，不需要 fetch 本地 JSON。图片仍然需要联网与原站可用。浏览器允许时复制使用 Clipboard API，受限或本地文件环境尝试浏览器的复制回退。

## 本地导入与构建

从可信的仓库根目录运行。源 HTML 是不可信数据，应保存在独立的数据目录中；不要在下载目录里启动 Python，不要执行源站 JavaScript。导入脚本只读本地归档路径，不访问网络。

```bash
python -I -X utf8 sites/costume-anime/scripts/import_catalog.py /absolute/path/to/source.html
python -I -X utf8 sites/costume-anime/scripts/build_gallery.py
```

导入只使用 `json.JSONDecoder` 解析 `const D` 和 `const META` 的 JSON，校验全部 1320 条原始记录（包括成人分类）的 ID、分类、路径模板、重复 ID、英文标签及中日字典覆盖、META 与分组数量。验证完成后才写 `data/catalog.json` 与 `manifest.json`。构建再次验证原始目录，并检查现存 manifest 与目录一致，防止手动编辑绕过安全边界。

默认 canonical 为 `https://example.com/costume-anime/`；部署构建通过 `SITE_URL=https://your-domain.example/costume-anime` 覆盖。主画廊复用 shared/ui.py 的导航、主题、语言、18+ 状态和对话框；落地页复用 shared/landing.py。翻译字典复用现有服装集的可信翻译模块，不依赖其图片或目录。
