# 二次元角色库

原生页面路径：`/character/`。收录 [たき AI 的角色组装 DB 公开版](https://charadb-2fi.pages.dev/)，本站独立编写界面与中文短名，保留日文名称及英文标签。

- 843 个基础条目：头发与眼睛 122、服装 440、姿势 281。
- 184 个发型换色版本单独计算，不重复作为基础卡片；姿势侧视图按原目录作为独立条目。
- 281 个姿势的原站线稿入口。
- 791 个基础条目默认可见，52 个泳装或偏性感条目需顶部 18+ 确认。普通双人日常动作不整类隐藏。
- 中日名称、英文标签和 ID 检索；带数量的分类按钮直接切换，默认隐藏的成人分类标记为 18+；收藏、放大和姿势线稿。
- 每张发型卡片提供棕、黑、金、粉、银五个色点，只改变当前卡片；详情换色会同步卡片。顶部统一发色会重设各卡片的预览色；重置恢复棕色。换色不修改已保存的收藏，星标保存当前展示版本。
- 卡片与详情页均可复制当前条目的原始英文标签，不拼接其他条目或自动补充人物标签。

## 图片与许可

图片通过浏览器从原站 HTTPS 地址读取，仓库与发布目录不保存这些图片，不提供批量下载或拼图导出。原图、线稿均链接原站。远程读取不代表获得图片再分发许可，原作者条件见 [NOTICE.md](NOTICE.md)。

联网且原站可用时显示图片；原站故障或离线时，名称、搜索、收藏和单条标签复制仍能使用。`index.html` 内嵌全部目录及脚本，直接 `file://` 打开不需要 fetch 元数据。收藏保存在 `pl.character.favorites.v1`；成人向隐藏时，对应条目与已打开的详情图片会隐藏。

本站只提供资源图库。服装/姿势的英文标签不额外添加示例角色的棕发与棕眼。

## 构建与目录更新

从仓库根目录构建：

```bash
python tools/build.py --site character
```

`data/catalog.json` 是本次接入保留的原站 `data.js` 公开版字段白名单快照，记录原文件 SHA-256。目录的 `built: 2026-11-02` 是原站版本标记；本站 `sites.json.updated: 2026-11-01` 是接入记录日期，用于 sitemap，不代表采集时间。原文件仅作 JSON 解析，不执行 JavaScript，不保留社区或额外下载入口。

维护者可手动保存新公开版 `data.js`，再导入：

```bash
python -I sites/character/scripts/import_catalog.py /path/to/data.js
```

来源条件与图片加载方式见 [NOTICE.md](NOTICE.md)。目录是人工审核后更新的快照，构建与预览不会自动同步原站。

新增条目须在 `scripts/translations.py` 添加自己的中文短名，审核 `scripts/build_gallery.py` 的默认隐藏规则，并更新 `sites.json` 数量。导入器拒绝非 public tier、重复 ID、未知 ID 与缺失父条目；不要用镜像仓库的汉化文件直接覆盖本站翻译。

```bash
python tests/test_character.py
```
