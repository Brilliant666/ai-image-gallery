使用说明使い方

photoai.life 是给画画、AI 出图用的参考图库合集。不用注册，打开即用；偏好设置只保存在你的浏览器里。photoai.life は、イラスト制作や AI 画像生成のための参考画像集です。登録不要で、設定はブラウザ内にだけ保存されます。

四个图库4 つのギャラリー

顶部栏可以随时切换，也可以按数字键 1–4，0 回到入口页。上部バー、または数字キー 1–4 で切り替えられます。0 でトップページへ。

  • 人像集ポートレート集1让 AI 生成的角色保持同一张脸。面部与造型两个分区，可按发型筛选，CC0 可商用。AI 生成キャラクターの顔を揃えるための人物参考。フェイスとスタイリングの 2 セクション、髪型で絞り込み、CC0。
  • 服装集衣装集2不含真人的纯服装图，86 个标签按颜色、单品、材质组合筛选，标签可直接作提示词。人物なしの衣装画像。色・アイテム・素材など 86 タグで組み合わせ検索、タグはそのままプロンプトに。
  • 姿势集ポーズ集3同一批姿势的线稿和深度图，一个开关切换，每个姿势 5 个视角，深度图可直接用于 ControlNet。同じポーズの線画と深度マップをスイッチで切り替え。各 5 アングル、深度マップは ControlNet にそのまま使えます。
  • CC0 姿势线稿CC0 ポーズ線画4另一个项目按同一份目录重新绘制的姿势线稿，每个姿势最多 5 个视角，CC0 可商用、可再分发。同じ目録で描き直された別プロジェクトのポーズ線画。各最大 5 アングル、CC0 で商用・再配布可。

浏览与筛选閲覧と絞り込み

  • 每个图库顶部的胶囊是分类（系列、季节、分区等），点一下只看这一类，数字是数量。各ギャラリー上部のチップは分類（シリーズ・季節・セクションなど）。数字は件数です。
  • 搜索框支持中文、日文和英文关键词，也能搜编号；按 / 直接跳到搜索框。検索欄は中国語・日本語・英語のキーワードと番号に対応。/ で検索欄へ移動します。
  • 「筛选」里还有更多条件：服装按颜色、单品、材质等标签组合筛选（多选为同时满足）；姿势按分类、视角筛选，可以按姿势分组或一张张看。「絞り込み」ではさらに条件を指定できます。衣装は色・アイテム・素材などのタグを組み合わせて（複数選択は AND）、ポーズは分類・アングルで絞り込み、ポーズごと／1 枚ずつ表示を切り替えられます。
  • 人像集的「人气 Top 10」来自原站的综合排行。ポートレート集の「人気 Top 10」は元サイトの総合ランキングです。
  • 往下滚动会自动加载更多。落地页（分类、标签页）里的「在画廊中查看」会带着筛选条件打开画廊。スクロールすると自動で続きを読み込みます。分類・タグのページの「ギャラリーで見る」は条件付きでギャラリーを開きます。
  • 右上角可以切换深浅色和中文 / 日本語，所有图库共用这些设置。右上でライト／ダーク、中文／日本語を切り替えられ、全ギャラリー共通です。

大图拡大表示

  • 点卡片打开大图。← → 或左右滑动切换，Esc 关闭。カードをクリックで拡大。← → または左右スワイプで切り替え、Esc で閉じます。
  • 大图里可以下载原图、在新标签页打开原图，或复制图片链接。卡片右上角的按钮可以直接下载。拡大表示から原寸のダウンロード・新しいタブで開く・画像リンクのコピーができます。カード右上のボタンからも直接ダウンロードできます。
  • 服装大图里点标签，会把这个标签加入筛选。衣装の拡大表示でタグをクリックすると、そのタグで絞り込みます。

线稿与深度图線画とデプス

姿势集的每张图都有线稿和深度图两个版本，像素完全对齐。ポーズ集の各画像には線画とデプスマップの 2 種類があり、ピクセル単位で一致しています。

  • 工具栏的开关或 D 键：整页在线稿和深度图之间切换。ツールバーのスイッチまたは D キーで、ページ全体を線画／デプスに切り替え。
  • 大图里的「对比」：拖动竖线左右对照两张图。↑ ↓ 换姿势，← → 换视角。拡大表示の「比較」で、縦線をドラッグして左右を見比べられます。↑ ↓ でポーズ、← → でアングル。
  • 深度图可以直接作为 ControlNet depth 的控制图；线稿可以用于 lineart / scribble，或作为构图参考。デプスはそのまま ControlNet depth の制御画像に、線画は lineart / scribble や構図の参考に使えます。
  • /pose-depth/ 是默认显示深度图的入口，和 /pose/ 是同一个模块。/pose-depth/ はデプス表示から始まる入口で、/pose/ と同じモジュールです。

配方与生图レシピと画像生成

配方把人像、服装、姿势各一项组合起来，生成可直接使用的提示词。四个图库共用同一份配方，切换图库不会丢失。レシピは、ポートレート・衣装・ポーズを 1 つずつ組み合わせて、そのまま使えるプロンプトを作る機能です。4 つのギャラリーで共通です。

  • 在大图里点「加入配方」或按 A；桌面上把鼠标移到卡片上，右上角的 + 也可以直接加入。同一类再加一项会替换原来的。拡大表示の「レシピに追加」か A キーで追加します。デスクトップではカード右上の + からも追加でき、同じ種類を追加すると置き換わります。
  • 配方栏常驻右下角，点开后向上展开：上面是人像、服装、姿势三个参考，下面是自动生成、可以修改的提示词，以及「图像生成」。展开时背后的页面照常浏览，可以继续往配方里加图。レシピバーは右下に常駐し、開くと上に広がります。上段にポートレート・衣装・ポーズの 3 つの参考、下段に自動生成され編集できるプロンプトと「画像生成」があります。開いたままでも後ろのページは閲覧でき、レシピへの追加も続けられます。
  • 点「生成」会用你自己的 API Key 调用所选服务商（OpenAI GPT Image、Google Gemini、豆包 Seedream、通义 Qwen-Image，或 OpenAI 兼容的中转），三张参考图和提示词会一起发过去。生成中可以切换到其他图库，完成后结果出现在配方栏里，可以放大、下载、删除。「生成」を押すと、ご自身の API Key で選んだサービス（OpenAI GPT Image、Google Gemini、Doubao Seedream、Qwen-Image、OpenAI 互換の中継）を呼び出し、3 枚の参考画像とプロンプトを送ります。生成中に別のギャラリーへ移動してもよく、完成した画像はレシピバーに表示され、拡大・保存・削除できます。
  • 中转用户在「生图服务」里选「自定义中转」，填 Base URL、Key 和模型 ID；按中转文档选择 images/edits（multipart，图片字段 image[] 或 image）或 images/generations（JSON 多图）。只填域名时自动补 /v1。也可以先点「测试连接」读取模型列表，这一步不会生成图片；部分服务商不提供模型列表，仍需实际生图验证。中継を使う場合は「カスタム中継」を選び、Base URL・Key・モデル ID を入力します。API 形式は images/edits（multipart、image[] または image）か images/generations（JSON 複数画像）から選べます。ドメインだけの場合は /v1 を補います。接続テストはモデル一覧の取得だけで画像は生成しません。一覧 API がないサービスは実際の画像生成で確認してください。
  • Key 只保存在你的浏览器里，由浏览器直接发给服务商，不经过本站服务器；默认只在当前标签页有效，勾选「记住」后才长期保存。费用按各服务商的价格计算。OpenAI 和 Gemini 不对中国大陆开放，大陆用户可以用豆包、通义或中转。Key はブラウザ内にのみ保存され、ブラウザから直接サービスへ送られます（本サイトのサーバーは経由しません）。初期状態ではこのタブの間だけ有効で、「記憶する」をオンにすると保存されます。料金は各サービスの規定に従います。
  • 不想在本站生成，也可以「复制提示词」或「下载参考拼图」，拿到其他工具里用。提示词按图 1、图 2、图 3 的顺序引用参考图，上传时按同样顺序。大图里的「复制提示词」只复制这一项的英文描述。本サイトで生成しない場合は「プロンプトをコピー」か「参考ボードを保存」で他のツールに持っていけます。プロンプトは画像 1・2・3 の順に参照するので、同じ順にアップロードしてください。拡大表示の「プロンプトをコピー」はその 1 件の英語の説明だけをコピーします。
  • 成人向内容不能加入配方。配方只保存在你的浏览器里。参考拼图需要在线打开本站才能下载，只供你自己出图参考，其中的姿势和服装图片同样不能再分发。成人向けの内容はレシピに追加できません。レシピはブラウザ内にのみ保存されます。参考ボードの保存はオンラインで開いたときのみ使え、ご自身の制作の参考用です。中のポーズ・衣装画像も再配布できません。

18+ 内容18+ コンテンツ

包括姿势里的双人交缠、全身性感系与上半身的聚胸、性感露骨分类，服装的内衣、性感两类，以及 CC0 线稿的全身・性感、双人系列与偏性感的姿势。ポーズ集の 2人絡み・全身セクシー系・上半身の胸寄せ／セクシー露骨寄り、衣装集のランジェリー・セクシー、CC0 線画の全身・セクシー、ふたり、suggestive なポーズが対象です。
